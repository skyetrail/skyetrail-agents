## The three fixes to make first

1. **Name a finish check the agent runs itself, and say its result settles done.** Lines 24 and 109-110 say "test each" and "Verify no regressions" without naming a command or a completion criterion. Put the check where the agent decides to stop, after the implementation order and before the reference material.
2. **Forbid weakening a check or editing a test to make it pass.** The file says nothing about this today. This is the skill an agent loads when a reviewer says "make it pass", so the sentence belongs here more than in most skills.
3. **Add a boundary section.** State what the skill does not cover, name the skill that takes over where it stops, and say that a direct instruction from the person wins over the skill. One edit clears four failing rules. `requesting-code-review` sits in the same collection and is the obvious counterpart.

Next after those: close the two open lists at lines 29-32 and 115-121 with a membership test, name the instruction file at line 30 or drop the parenthetical, and state the finished outcome in the first lines.
