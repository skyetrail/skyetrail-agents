## The three fixes to make first

1. **F-5. Forbid weakening a check or editing a test to make it pass.** The skill sends an agent to
   edit code under review pressure and, at lines 90-96, to delete code a reviewer questioned. Nothing
   stops it from deleting or loosening a failing test to clear a review item. This is the finding with
   the quietest failure mode, because the run then looks successful.
2. **F-4. Name a check the agent runs itself, whose result settles whether the work is done.** Lines
   108-111 say "Test each fix individually" and "Verify no regressions", with no command and no
   criterion. As written, an agent reports the review addressed having run nothing.
3. **F-2. State what the skill does not cover, and name the skill that takes over.** No boundary
   section exists. `requesting-code-review`, `verification-before-completion` and `writing-plans` all
   sit in the same collection and all resolve by name.

F-3, the closed lists at lines 29-32, 106 and 115-121, is the next one. Line 143 already shows the
closing form this file needs, applied in one place out of four.
