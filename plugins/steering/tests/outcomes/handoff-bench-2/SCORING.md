# Scoring bench two

Same procedure as bench one, so the two are comparable: three runs per arm, fresh agent each
run, same worker model, the key never in a runner's prompt, and a scorer that sees one report
and the key but never the fixture. Counting is arithmetic: found is distinct key ids mapped,
missed is nine minus found, false alarms is findings mapping to a decoy or to nothing.

What this bench answers that bench one could not:

- Whether the cycle 2 wording holds on code it was never tuned against, in another language.
- Whether the widened injection rule works on interpreters no subtype list would name (J2, J3).
- Whether the sharpened decoy rule still reports a real authorization gap where a comparator
  exists (J9) while ignoring a pure style difference (E4).
- Whether the shape rule generalizes past logs to another way a secret leaves the process (J6).

Bench one saturated at eight of eight, so it can no longer show improvement. This one has nine
problems and four decoys.
